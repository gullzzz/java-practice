## 4.1 数组的基本概念

**定义**：数组是同一种类型元素的定长有序集合，在内存中连续存储。它是引用类型，变量本身存的是堆中数组对象的地址。长度在创建时确定后不可改变，通过从0开始的整数索引访问元素。

**解决问题/用途**：当你需要存储一组同类型数据时，声明 N 个单独变量显式见拙——`score1, score2, score3...`。数组让你用单个变量管理批量数据，通过索引遍历和操作，是批量数据处理的基础。性能上由于内存连续，访问任意元素都是 O(1)，是所有集合类型中最快的。

```java
// 方式1：声明 + 分配
int[] arr = new int[5];   // 分配5个int空间，默认值0
arr[0] = 10;

// 方式2：声明 + 初始化
int[] arr = {1, 2, 3, 4, 5};
String[] names = {"张三", "李四", "王五"};
```

核心特性：
- **长度固定**：创建后不可改变
- **索引从 0 开始**：`arr[0]` 是第一个元素
- 访问越界会抛 `ArrayIndexOutOfBoundsException`
- `arr.length` 获取长度（属性，不是方法）
- 数组是**引用类型**，存储在堆上

## 4.2 数组遍历

**定义**：数组遍历是指依次访问数组中每个元素。常用两种方式：普通 for 循环（有索引，可以获取和修改元素）和 for-each 循环（简洁但只能读取，不能修改）。

**解决问题/用途**：绝大多数数组操作——求和、找最大值、过滤、映射——都需要遍历。选择哪种方式取决于需求：需要修改元素或用索引做计算时用普通 for，单纯读取每个元素时用 for-each。

```java
int[] scores = {85, 92, 78};

// 普通 for（有索引，可修改元素）
for (int i = 0; i < scores.length; i++) {
    scores[i] += 5;  // 可以修改
    System.out.println(scores[i]);
}

// for-each（无索引，无法修改元素）
for (int s : scores) {
    // s 是副本，修改 s 不影响原数组
    System.out.println(s);
}
```

## 4.3 二维数组

**定义**：二维数组本质是"数组的数组"——外层数组的每个元素本身也是一个数组。这种设计使得 Java 的二维数组支持不规则结构（每行的列数可以不同）。

**解决问题/用途**：表格类数据（学绩表、棋盘、矩阵运算）天然是二维结构。Java 的"数组的数组"设计让内存可以非连续分配，且支持不规则结构——比如存储一个三角形的杨辉三角，每行长度不同也不浪费空间。

```java
// 声明
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 遍历
for (int i = 0; i < matrix.length; i++) {       // 行
    for (int j = 0; j < matrix[i].length; j++) { // 列
        System.out.print(matrix[i][j] + " ");
    }
}
```

Java 的二维数组本质是**数组的数组**：
- `matrix` 是 `int[][]`
- `matrix[0]` 是 `int[]`
- `matrix[0][0]` 是 `int`

因此支持**不规则数组**（每行列数可以不同）：
```java
int[][] jagged = {
    {1},
    {2, 3},
    {4, 5, 6}
};
```

## 4.4 Arrays 工具类

**定义**：`java.util.Arrays` 是 JDK 提供的数组操作静态工具类，包含排序、查找、填充、复制、比较等常用方法，弥补了数组本身方法少的不足。

**解决问题/用途**：数组是 JDK 1.0 就存在的老 API，方法极少。排序不能用 `arr.sort()`，查找不能 `arr.find(5)`。Arrays 工具类覆盖了所有日常数组操作需求，让你不需要手写排序和查找算法就能高效处理数组。

`java.util.Arrays` 提供常用数组操作：

| 方法 | 作用 | 示例 |
|------|------|------|
| `toString(arr)` | 转为字符串 | `[1, 2, 3]` |
| `sort(arr)` | 原地排序（升序） | `{3,1,2} → {1,2,3}` |
| `binarySearch(arr, key)` | 二分查找 | 返回索引，未找到返回负数 |
| `fill(arr, val)` | 填充值 | 所有元素变为指定值 |
| `copyOf(arr, len)` | 复制数组 | 返回新数组 |
| `copyOfRange(arr, from, to)` | 部分复制 | `[from, to)` |
| `equals(arr1, arr2)` | 比较内容 | true/false |

**重要**：`binarySearch` 要求数组**已排序**。

## 4.5 常见算法

**解决问题/用途**：在学习阶段理解这些基础算法的手动实现，有助于掌握循环、条件判断、数组操作的组合使用技巧，培养算法思维。实际开发中优先使用 Arrays 工具类或集合框架的现成方法。

### 找最大/最小值
```java
int max = arr[0];
for (int v : arr) {
    if (v > max) max = v;
}
```

### 反转数组
```java
for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
```

### 冒泡排序
时间复杂度 O(n²)，适合理解排序原理：
```java
for (int i = 0; i < arr.length - 1; i++) {
    for (int j = 0; j < arr.length - 1 - i; j++) {
        if (arr[j] > arr[j + 1]) {
            // 交换 arr[j] 和 arr[j+1]
        }
    }
}
```

## 4.6 数组 vs 集合

**定义**：数组是 Java 语言内置的最基本数据容器，长度固定。集合（ArrayList、HashMap 等）是 Java 集合框架提供的高级数据容器，长度动态可变，功能丰富。

**解决问题/用途**：数组适合"大小确定且不需要变动"的场景（如一年12个月的数据），性能最高。集合适合"大小不确定、需要增删"的场景（如用户的购物车、搜索结果列表），更灵活易用。现代 Java 开发中，集合是大部分情况下的默认选择。

| | 数组 | 集合(ArrayList等) |
|------|------|------|
| 长度 | 固定 | 可变 |
| 元素类型 | 基本类型或引用类型 | 只能引用类型 |
| 泛型 | 不支持 | 支持 |
| 性能 | 更快 | 稍慢（有额外开销） |
| 工具方法 | 少（Arrays类辅助） | 丰富 |

Java 中更推荐使用集合，将在阶段 8 详细讲解。

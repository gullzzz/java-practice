# 多态——面试常考内容

---

## Q1：什么是多态？Java中如何实现多态？

**答**：多态是指同一行为具有多个不同表现形式。Java中通过以下条件实现：

1. 继承（extends）或实现接口（implements）
2. 子类重写父类方法
3. 父类引用指向子类对象

运行时通过**动态绑定**确定调用哪个方法——看实际对象类型，不看引用类型。

---

## Q2：向上转型和向下转型的区别？

**答**：

| | 向上转型 | 向下转型 |
|------|----------|----------|
| 方向 | 子类 → 父类 | 父类 → 子类 |
| 写法 | `Animal a = new Dog()` | `Dog d = (Dog) a` |
| 是否自动 | 自动 | 必须强转 |
| 安全性 | 绝对安全 | 可能ClassCastException |
| 访问限制 | 只能访问父类成员 | 可访问子类特有成员 |

---

## Q3：instanceof 的作用？Java 16有什么改进？

**答**：`instanceof` 用于判断对象的实际类型，避免向下转型时抛出 `ClassCastException`。

Java 16引入**模式匹配**，将判断和转换一步完成：

```java
// 传统写法
if (obj instanceof Dog) {
    Dog d = (Dog) obj;
    d.wagTail();
}

// Java 16+
if (obj instanceof Dog d) {
    d.wagTail();  // 直接使用变量d
}
```

## Q4：静态方法、成员变量、私有方法能否实现多态？

**答**：**都不能。**

- **静态方法**：属于类而非对象，编译时已确定调用哪个类的静态方法
- **成员变量**：看引用类型，不看实际对象类型（字段隐藏，非重写）
- **私有方法**：不能被子类重写，不存在多态的前提

只有**实例方法**的**重写**才能触发多态。

---

## Q5：重写（Override）和重载（Overload）对多态的影响？

**答**：

- **重写（Override）**：多态的**核心机制**。子类重新定义父类方法，运行时根据实际对象类型调用对应方法。
- **重载（Overload）**：与方法多态**无关**。重载在编译时确定调用哪个版本（静态绑定），只看参数列表。

---

## Q6：构造方法中调用可重写方法的陷阱？

**答**：父类构造方法中如果调用了可被重写的方法，子类构造时会执行子类重写的版本，但此时**子类字段尚未初始化**，可能导致意外行为。

```java
class Parent {
    Parent() { print(); }  // 调用了可重写方法
    void print() { System.out.println("Parent"); }
}
class Child extends Parent {
    String name = "child";
    void print() { System.out.println(name.length()); }
    // new Child() → NullPointerException（此时name还是null）
}
```

**规则**：构造方法中不要调用可被重写的方法。

## Q7：多态在集合框架中的典型应用？

**答**：用接口/父类类型声明集合，存储不同子类对象：

```java
List<String> list = new ArrayList<>();  // List是接口，ArrayList是实现
Map<String, Integer> map = new HashMap<>();
```

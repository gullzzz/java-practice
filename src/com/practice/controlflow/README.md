## 2.1 if / else if / else

**定义**：条件分支语句，根据布尔表达式的真假来决定执行哪段代码。程序从第一个 if 开始自上而下检查，命中第一个 true 分支就执行对应的代码块，跳过后续所有分支。

**解决问题/用途**：程序的核心能力是根据不同条件执行不同逻辑——登录成功跳首页、登录失败提示错误；VIP用户多折扣、普通用户少折扣。if/else 是最基础的"决策"机制，让程序不再是死板的从上到下一行不落。

```java
if (条件1) {
    // 条件1为true时执行
} else if (条件2) {
    // 条件1为false，条件2为true时执行
} else {
    // 所有条件都不满足时执行
}
```

执行顺序：**从上到下，匹配到第一个 true 就停止**。

## 2.2 switch（传统写法 vs 新写法）

**定义**：多路分支选择语句，根据一个变量的值匹配多个 case 标签，执行匹配到的分支。传统 switch 使用穿透机制（需 break 跳出），增强 switch（Java 14+）用箭头语法消除穿透并支持作为表达式返回值和模式匹配。

**解决问题/用途**：当一个变量有多个离散取值且每个值对应不同处理逻辑时，if-else 层层嵌套会又臭又长，switch 直接把取值和处理一对一列出，可读性远胜多层 if-else。典型场景：根据星期几执行不同任务、根据 HTTP 状态码做不同处理、根据操作码执行不同命令。

### 传统 switch（穿透机制）

```java
switch (变量) {
    case 值1:
        // 代码
        break;  // 必须有，否则会继续执行下一个case
    case 值2:
        // 代码
        break;
    default:
        // 所有case都不匹配时执行
}
```

支持的类型：`int`/`byte`/`short`/`char`、`String`（Java 7+）、`enum`。

**fall-through（穿透）**：没有 `break` 时，会继续执行下一个 case。偶尔有意图地使用（多个 case 共享逻辑）：

```java
case 6:
case 7:
    System.out.println("周末");
    break;
```

### 增强 switch（Java 14+）

```java
// 箭头语法，不需要break
String type = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "无效";
};

// switch 表达式 + yield 返回值
String result = switch (day) {
    case 1 -> "周一";
    case 5 -> {
        System.out.println("TGIF!");
        yield "周五";  // 代码块中用 yield 返回值
    }
    default -> "其他";
};
```

关键改进：箭头语法消除穿透；switch 可直接作为表达式赋值。

## 2.3 for 循环

**定义**：for 是一种由初始化、条件检查、迭代更新三部分组成的计数型循环结构。初始化只执行一次，之后每次循环前检查条件，条件为 true 则执行循环体，然后执行迭代更新，如此往复直到条件为 false。

**解决问题/用途**：程序中最常见的需求之一就是"重复做某事 N 次"——遍历数组、批量处理 1000 条数据、打印九九乘法表。for 循环将初始状态、终止条件、迭代步进集中在一行，结构紧凑清晰，适合已知循环次数的场景。

```java
for (初始化; 条件; 每次迭代后执行) {
    // 循环体
}

// 示例
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```

执行顺序：**初始化 → 检查条件 → 执行体 → 迭代后操作 → 检查条件 → ...**

- `初始化` 只执行一次
- `条件` 每次循环前检查
- `迭代后操作` 每次循环体执行完后执行

### 嵌套循环

外层每执行 1 次，内层执行完整的一轮：

```java
for (int i = 1; i <= 9; i++) {        // 外层9次
    for (int j = 1; j <= i; j++) {    // 内层1到i次
        System.out.print(j + "×" + i);
    }
    System.out.println();
}
```

## 2.4 while 与 do-while

**定义**：while 是先判断条件再执行循环体的循环结构，条件为 true 才进入，可能一次都不执行。do-while 是先执行再判断，循环体至少执行一次。

**解决问题/用途**：很多场景你不知道要循环多少次——读取文件到末尾、等待用户输入 quit、轮询任务状态直到完成——while 适合"满足条件就一直做"的模式。do-while 适合"至少做一次再决定是否继续"，比如显示菜单至少显示一次、读取配置至少尝试一次。

```java
// while：先判断，可能一次都不执行
while (条件) {
    // 循环体
}

// do-while：先执行一次，再判断（至少执行一次）
do {
    // 循环体
} while (条件);
```

选择原则：
- 知道循环次数 → `for`
- 不知道循环次数 → `while`
- 至少需要执行一次 → `do-while`

## 2.5 break 与 continue

**定义**：break 用于立即终止并跳出当前循环（或 switch）。continue 用于跳过当前迭代的剩余代码，直接进入下一次迭代的条件检查。

**解决问题/用途**：循环中常有"提前结束"的需求——找到了目标元素就不必继续遍历（break），或者当前元素不符合条件就跳到下一个（continue）。带标签的 break/continue 进一步解决了"如何从内层循环直接跳出外层循环"的问题，避免了设置额外标志变量的麻烦。

| 关键字 | 作用 |
|--------|------|
| `break` | 立即**跳出**当前循环 |
| `continue` | 跳过当前迭代，进入**下一次**循环 |

### 带标签的 break/continue

```java
outer:
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        if (i == 3) break outer;  // 跳出外层循环
    }
}
```

用于跳出多层嵌套循环。`continue` 也可以带标签。

## 2.6 增强 for（for-each）

**定义**：for-each 是 Java 5 引入的简化遍历语法，隐式使用迭代器依次取出集合或数组中的每个元素赋值给临时变量，无需手动维护索引或迭代器。

**解决问题/用途**：传统 for 遍历需要写 `int i = 0; i < arr.length; i++`，代码冗长且容易写出越界 bug。for-each 消除了索引变量和边界检查的负担，让你专注"对每个元素做什么"，代码量减半，安全性更高。适用于绝大多数"遍历每个元素"的场景。

```java
int[] arr = {1, 2, 3, 4, 5};
for (int n : arr) {
    System.out.println(n);
}
```

- 无需索引，遍历所有元素
- **不能修改数组元素**（只是读到临时变量中）
- 适用于数组和所有实现 `Iterable` 接口的集合

## 2.7 死循环

**定义**：条件永远为 true 的循环，不会自行终止。必须通过 `break`、`return` 或异常在循环体内部退出。

**解决问题/用途**：服务器的消息监听、游戏的主循环、命令行交互式程序（等待用户每次输入），这些场景需要程序"一直运行直到主动退出"，死循环正是表达这种"永远在线"逻辑的标准写法。

```java
for (;;) { }         // for 死循环
while (true) { }     // while 死循环
```

需要在循环体内部用 `break` 退出。

---

## 2.8 编码建议

1. **循环变量用有意义的名字**，避免 `i`、`j` 以外的单字母
2. **避免深层嵌套**（超过 3 层），可提取方法
3. **for-each 优先于普通 for**，当不需要索引时
4. **switch 保持简单**，复杂分支逻辑考虑用 if-else 或策略模式

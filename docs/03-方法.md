## 3.1 方法的定义

```java
修饰符 返回类型 方法名(参数类型 参数名, ...) {
    // 方法体
    return 返回值;  // 如果返回类型不是 void
}
```

```java
// 无参数，无返回值
static void greet() {
    System.out.println("Hello!");
}

// 有参数，有返回值
static int add(int a, int b) {
    return a + b;
}
```

- **方法名**：动词开头，驼峰命名（`calculateTotal`）
- **参数**：方法需要的输入，类型必须指定
- **返回值**：`void` 表示没有返回值；`return` 语句结束方法并返回值

## 3.2 参数传递机制

**重要！Java 只有值传递**，但引用类型传递的是"引用的副本"：

```java
// 基本类型：传值的副本
void changeValue(int x) {
    x = 999;  // 不影响调用处的变量
}

// 引用类型：传引用的副本（但副本指向同一个对象）
void changeArray(int[] arr) {
    arr[0] = 999;  // 会影响原数组内容！
}
```

图解：
```
基本类型传参：copy 值
  a=10  →  copy of 10 →  x=10 (x改了不影响a)

引用类型传参：copy 引用
  arr → [0x100] → {1,2,3}
        copy of [0x100] → 指向同一个数组 → 修改影响原数组
```

## 3.3 方法重载（Overload）

**同名方法，参数列表不同** → 编译器根据传参自动选择：

```java
static int max(int a, int b) { ... }
static double max(double a, double b) { ... }
static int max(int a, int b, int c) { ... }
```

重载规则：
1. 方法名相同
2. 参数列表不同（个数、类型、顺序）
3. **返回类型不同不算重载**（编译错误）
4. 与参数名无关

编译器选择"最匹配"的版本。

## 3.4 可变参数（varargs）

```java
static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    return total;
}

sum(1, 2);        // numbers = {1, 2}
sum(1, 2, 3, 4);  // numbers = {1, 2, 3, 4}
sum();            // numbers = {} (空数组)
```

- `int...` 本质是 `int[]`，但调用更灵活
- 一个方法只能有一个可变参数，且必须在最后

## 3.5 递归

方法调用自身：

```java
static int factorial(int n) {
    if (n <= 1) return 1;       // 基准条件（终止条件）
    return n * factorial(n - 1); // 递归调用
}

factorial(5)
→ 5 * factorial(4)
→ 5 * 4 * factorial(3)
→ 5 * 4 * 3 * factorial(2)
→ 5 * 4 * 3 * 2 * factorial(1)
→ 5 * 4 * 3 * 2 * 1 = 120
```

递归三要素：
1. **基准条件**（终止递归的条件）—— 必须存在！
2. **每次递归向基准条件靠近**
3. **递归调用自身**

注意：递归层次太深会导致 `StackOverflowError`（栈溢出）。

## 3.6 static 方法的含义

```java
static int add(int a, int b) { ... }
```

- 属于**类本身**，不属于任何实例
- 调用方式：`ClassName.method()` 或同类中直接 `method()`
- 没有 `this` 引用
- main 方法必须是 static（程序启动时还没有任何对象）

---

## 3.7 方法设计原则

1. **单一职责**：一个方法只做一件事
2. **命名清晰**：方法名应准确描述其功能
3. **参数不宜过多**：超过 3-4 个考虑封装为对象
4. **短方法**：一般不超过 20-30 行
5. **无副作用更好**：优先写不修改外部状态的方法
